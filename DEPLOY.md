# Як викласти сайт (папка `dist/`)

Статичний сайт: 5 сторінок, без бази даних і без CMS. Працює на будь-якому хостингу, що віддає звичайні файли.

| Сторінка | Адреса |
|---|---|
| Головна | `/` |
| Теплові насоси | `/teplovi-nasosy/` |
| Сонячні станції | `/sonyachni-stantsii/` |
| Зарядні станції | `/zaryadni-stantsii/` |
| Кредит від 0% | `/kredyty/` |

## Як викласти

1. Завантажте **вміст** папки `dist/` у корінь сайту `www.techno-as.com.ua`. Тобто `index.html` має лежати в корені, а не в підпапці.
2. Звичайний хостинг (Apache, FTP): файл `.htaccess` уже налаштовує сторінку 404, стиснення й кешування. Не забудьте його скопіювати: файли з крапкою на початку назви часто приховані.
3. Netlify або Cloudflare Pages: підключіть цей репозиторій і вкажіть папку публікації `dist` (команда збірки не потрібна) або перетягніть папку `dist` у панель. Кешування для цих сервісів налаштовує файл `_headers`.
4. Nginx: `root` — папка `dist`, `try_files $uri $uri/ =404; error_page 404 /404.html;`. Для `/assets/` поставте кеш на рік, бо назви файлів там змінюються з кожною збіркою.

Адреси старого сайту, яких тут немає, варто перенаправити 301-редиректом на найближчу нову сторінку, щоб не втратити позиції в Google.

## Налаштування (`config.js`)

`config.js` не кешується, тож зміни в ньому діють одразу.

```js
window.TA_FORM_ENDPOINT = '';      // куди слати заявки
window.TA_LIVE_ENDPOINT = '';      // жива генерація станції
window.TA_MASCOT_MODE = 'always';  // Інженер IS: 'always' | 'tips' | 'off'
```

- **Заявки.** Поки адреса порожня, після натискання на кнопку відкривається пошта відвідувача з готовим листом на tehno.as.lviv@gmail.com, і заявка дійде, лише якщо людина його надішле. Щоб заявки з обох форм (першого екрана й контактів) приходили в Telegram самі, розгорніть обробник із папки [`telegram-worker/`](telegram-worker/README.md) і впишіть його адресу сюди.
- **Жива генерація.** Адреса, що віддає JSON `{"power_kw": 4.2, "today_kwh": 18.5, "place": "Львів"}`, наприклад проксі до хмари інвертора Deye, Huawei чи Solis. Поки адреса порожня, блок прихований.
- **Інженер IS.**
  - `always` — завжди в кутку;
  - `tips` — з'являється, лише коли для блоку є нова порада;
  - `off` — вимкнено.

  Відвідувач також може сховати його сам, і сайт це запам'ятає. Повернути його можна посиланням у футері.

## Що вже зроблено для пошуку й швидкості

- Окремі title, description і canonical для кожної сторінки, картинки для поширення (`/og/*.jpg`), розмітка Schema.org: LocalBusiness, Service, FAQPage, BreadcrumbList.
- `sitemap.xml` і `robots.txt`. Після запуску додайте сайт у Google Search Console і надішліть `https://www.techno-as.com.ua/sitemap.xml`.
- Фото у WebP у кількох розмірах: телефон завантажує менші. Фото нижче першого екрана вантажаться, лише коли до них доходить прокрутка.
- Шрифт Manrope лежить на самому сайті, без Google Fonts. Стилі вбудовані в сторінку, скрипт підключається після показу.
- Lighthouse (телефон, локально): швидкодія 94–98, доступність / найкращі практики / SEO — 100.
